# Student Performance Analyzer

A Python project that analyzes student academic performance using Pandas, NumPy and Matplotlib.

## Features

- Reads student records from a CSV file
- Validates student marks
- Calculates total marks and percentages
- Assigns grades based on percentages
- Calculates class mean, median and standard deviation
- Identifies the class topper
- Calculates subject-wise averages
- Displays a student percentage bar chart
- Displays a marks distribution histogram

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## Installation

Install the required libraries:

```bash
pip install pandas numpy matplotlib
```

## How to Run

Keep `students.csv` in the same directory as the Python file.

Run the program:

```bash
python student_performance_analyzer.py
```
